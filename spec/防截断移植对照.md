# 脚本层防截断 · 移植前后逐项对照

一句话：把「芳乃预设 v2.8.1」那条脚本里的**脚本层防截断**（原作 Kemini Dramatron v3.1 的
`scripts[0]`，作者 Kemini）搬进我们这支面板，接上已有的「🛡 防截断」按钮，并让按钮真的
装/卸拦截器——**在这之前那个按钮只切开关+存盘，没有任何防护**。

| 项 | 值 |
|---|---|
| 素材 | `_port/antitrunc-extracted.txt`（从 v2.8.1 那条 13.8 万字脚本里原样抽出的 1532 行 / 5.56 万字，本机移植用，不进库） |
| 落点 | `panel/src/antitrunc.js`（1630 行 / 61.3KB，其中核心段 1444 行逐字来自素材） |
| 注入方式 | `tools/build-panel.mjs` 把它整体塞进 `panel/src/panel-core.js` 的 `FANO_ANTITRUNC_BEGIN/END` 之间 |
| 面板脚本体积 | 入库版 101.1KB（字节）→ 现在 167.1KB（字节，14.6 万字） |
| 机械核对 | `node _port/check-port.mjs` —— 核心段与素材**逐行**比对（只允许下面第三节列出的改写） |

## 一、它到底干了什么（原理）

1. 拦下发往 `api/backends/<后端名>/generate` 的 `fetch`；
2. 往请求里塞一个**合成的 function-call 定义**（名字是 `emit_complete_response_<随机 12 字节 hex>`，
   每次请求都换，避免和用户自己的工具重名），把 `tool_choice` 设成 `auto`；
3. 在对话里插一句控制提示，要求模型"把最终正文整个放进那个函数的 `content` 参数，别写在调用之外"。
   控制提示优先插在**锚点 `<format>` 之前**（本预设 💠continue 条目里有这个标签，与 Kemini 一致）；
   找不到锚点就追加到末尾，并且**警告一声**（不是静默降级）；
4. 模型于是把正文从函数调用参数里吐回来。上游回来的 SSE/JSON 被改写：把参数里的正文解码成普通正文，
   `finish_reason` 由 `tool_calls` 改回 `stop`，并剥掉那个合成 `tool_calls`；
5. 于是正文绕过了「纯文本流被渠道掐断」那条路——这条路上的字符是按参数分片传的，中途断掉也能靠
   增量解码器把已经拿到的部分救回来。

## 三、相对素材改了哪几处（全部可核对）

只有下面四处，`node _port/check-port.mjs` 会把搬进来的核心段按这几处**反向还原**后与素材逐行比：

| # | 改动 | 为什么 |
|---|---|---|
| 1 | 标识符改名：`describeError$1→describeError`、`resolveUrl$1→resolveUrl`、`MARKER$1→MARKER`、`GENERATION_ENDPOINT$1→GENERATION_ENDPOINT`、`attempt2→attempt`，并去掉打包器留下的 `/* @__PURE__ */` 标注 | 这些 `$1` 是打包产物，留在源文件里不好读；纯改名，不涉行为 |
| 2 | `install()` 里宿主窗口的取法：`window.parent ?? window` → `hostWindow()`（一路爬到**最外层同源窗口**），跨域返回 `null` 时**宁可不装** | 酒馆助手脚本跑在 iframe 里，手机上还可能是嵌套 iframe，而 `generate` 请求是**最外层**窗口发的。只往上看一层就会装到中间的 iframe 上——开关开着却什么也没拦到。这条也是 `panel-core.js` 里挂载点 `HOST` 用的同一套爬法 |
| 3 | 引导层重写（素材第 1460 行之后那段）：**不再注册按钮**；开关读写改成"调用方传键 + 容忍多种写法"；装/卸由 `setEnabled()` 连做；新增 `defaultOn`（出厂默认值）；控制台 API 同时挂 `globalThis` 与宿主窗口 | 见第四节第 1 条（双接线）与第六节（存档兼容） |
| 4 | 位置：核心段作为一个普通函数塞在面板 IIFE 里（`createAntiTruncation()`），所有名字都在函数作用域内 | 面板脚本只有一个 IIFE，不能有 import/export；这样也不会和面板里的同名变量打架 |

## 四、没搬的 / 故意不一样的

| 项 | 为什么不搬 |
|---|---|
| **按钮注册**（`appendInexistentScriptButtons` / `getButtonEvent` / `eventOn`） | 两处都注册会把**一次点击变成两次切换**（等于点一下没反应，而且每点一次多挂一个监听）。按钮统一由 `panel-core.js` 声明并接线，`antitrunc.js` 只管开关本身 |
| **静态按钮声明** | 仍在 `tools/build-preset.mjs`（酒馆助手不认运行时注册）。但名字与开关**单一来源**在面板的 `CONFIG.button`，`build-preset` 读它来写 `button.buttons`，两处不会再各写一份 |
| v2.8.1 那条脚本的其余功能（正文美化正则、选项栏、变量总线、它自己的拖动/隐藏…） | 不在本次范围。正则那 7 条是上一批移植的（`preset/fano-regex-extra.json`），本批不动 |
| 把开关画进面板界面 | 只有两个入口：顶部「🛡 防截断」按钮 + 控制台 `__FANO_ANTITRUNC__`。加界面控件属于产品决定，不在本次任务里 |
| `panel-core.js` 的 `diagnose()` 里加防截断状态 | 控制台 API 已经能查（`__FANO_ANTITRUNC__.installed()`），而 `diagnose()` 本身也只在控制台里跑得到，加了没有实际收益 |

## 五、没验证到的（老实说）

- **真渠道上的实际效果没验**：要发真实请求给真实端点（并且要能复现"被截断"），本机没有这样一条渠道。
  验到的是两层：**请求确实被改写**（多出合成函数 + 控制提示挂在锚点前 + `tool_choice=auto`）、
  **响应确实被还原**（正文从参数里解出来、`finish_reason` 改回 `stop`、合成 `tool_calls` 剥掉）。
  这两层用假上游在 Node 里跑通（`test-panel.mjs [13]`，含分块流式与 `lastRun()` 记录）。
- **Google 方言没发过真请求**：只能靠核心段逐行核对 + 结构推理（本机没有 Gemini 渠道可试）。
- **手机真机上的嵌套 iframe 没验**：爬法用假 DOM 的两层/三层链验证了（`test-iframe.mjs [1]`：
  装在**最外层**、中间层与内层都没被碰），真机没试。
- **浏览器两层回归**（`check-browser` 58 项 / `check-gui-browser` 205 项）跑的是面板几何与编辑器十屏，
  **不涉及防截断这条路径**——它们通过只能说明"没有把别的东西弄坏"。

## 六、开关与存档约定

| 事 | 约定 |
|---|---|
| 键 | `fano-antitrunc-v1`（`panel-core.js` 的 `LS.antitrunc`，**故意不跟面板 ID 走**） |
| 写入格式 | `"1"` / `"0"` —— 这是**这个键的原主人**（v2.8.1）认的写法，换回那一支时用户的选择跟着走 |
| 读取容忍 | `"1"/"0"`（v2.8.1）、`"true"/"false"`（本面板上一版按钮用 `JSON.stringify` 写的）、键不存在 → 用出厂默认；**认不出来的脏值一律按开启**（宁可多一层，也不因一个坏值把防护悄悄关掉） |
| 出厂默认 | `CONFIG.antitrunc.enabled`（面板里 `defaultOn`）。它只在**键还没写过**时起作用；用户点过按钮之后以用户点的为准 |
| 装/卸 | 开 = 往宿主窗口的 `fetch` 挂包装；关 = **整个摘掉**（`window.fetch` 回到原样）。不是只改一个标志位 |
| 装不上的时候 | 开关照记，但 `installed=false`：按钮会提示"开关已打开，但拦截器没装上"，控制台也有明确一行。**绝不假装成功** |
| 渠道不支持时 | 只提醒（同一档位只提醒一次），**绝不自动关用户的开关** |
| 出厂关着的预设 | `CONFIG.button.enabled=false` 时顶部按钮既不静态声明也不接线；`CONFIG.antitrunc.enabled=false` 时启动不装拦截器 |

## 七、怎么复验（命令与期望）

```powershell
node _port/mk-antitrunc.mjs      # 需要重搬核心段时跑（幂等）
node _port/check-port.mjs        # 核心段与素材逐行核对 → ✓ 逐行一致
node tools/build-all.mjs         # 整条链；build-panel 会把模块注入面板并做语法检查
node tools/test-panel.mjs        # 通过 137 项，失败 0 项（[13] 就是防截断那一段）
node tools/test-panelconfig.mjs  # 通过 94 项，失败 0 项（含"成对加字段/不丢字段"）
node tools/test-iframe.mjs       # 通过 33 项，失败 0 项（含"装到最外层窗口"与"跨域宁可不装"）
```

浏览器两层要本机 Chrome（沙箱里 Chrome 派生会被拒，需要更宽权限）：

```powershell
node tools/check-browser.mjs       # 通过 58 项，失败 0 项
node tools/check-gui-browser.mjs   # 页面自检 通过 205 项，失败 0 项
```

出错时先在控制台看这两个入口：

```js
__FANO_ANTITRUNC__.isEnabled()      // 开关（用户的选择）
__FANO_ANTITRUNC__.installed()      // 拦截器到底装上没有
__FANO_ANTITRUNC__.lastRun()        // 最近一次请求的结果：outcome / 字数 / 分块 / 是否走普通通道
```
