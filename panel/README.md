# 芳乃 · 预设面板 v0.1.0

一个**酒馆助手（JS-Slash-Runner）脚本**。悬浮窗形式，把当前酒馆预设里的条目按**子集**重新组织：

- **单选子集** → 下拉框。选一个，自动关掉同组其他（人称、主文风、思维链、字数…）。
- **多选子集** → 开关排。可以叠着开（追加文风、防护开关、适配…）。
- **破甲** → 一个**整组互斥**的下拉框：选 Gemini 就开满 Kemini 那 21 条并关掉另外两组；选 DeepSeek / GLM 换成梦鲸那 6 条；选其他模型换成 Izumi 那 13 条。
- **核心子集** → 固定，面板不碰（槽位与结构条目）。

配色是芳乃 / 千恋万花两套（白天 + 夜间）。

## 文件

| 文件 | 用途 |
|---|---|
| `fano-panel.js` | **装进酒馆的脚本本体**。自动生成，别手改；改 `src/panel-core.js` 或 `spec/groups.json` 后重新构建。 |
| `preview.html` | **离线预览**。双击就能在浏览器里看，用的是内存假数据和假的酒馆助手 API。 |
| `preview-host.js` | 预览用的假数据（三份源预设的条目并集，393 条），自动生成。 |
| `src/panel-core.js` | 面板源码。 |

## 装进酒馆

1. 装好并启用 **酒馆助手（JS-Slash-Runner）** 扩展。
2. 打开酒馆 → 扩展 → 酒馆助手 → 脚本库 → 新建脚本。
3. 把 `fano-panel.js` 全文粘进去，保存并启用。
4. 左下角会出现一个写着「芳」的圆球，点它开合面板。

不需要给脚本配按钮（脚本自带的悬浮球就是入口）。

## 用法

面板是**手风琴式**的：21 个模块默认全部折起，只显示一行标题。

- **点模块标题那一行**展开，再点一次折回。想改哪个就开哪个，可以同时展开多个。
- **折起时标题右边仍然显示当前状态**：`主文风` 直接写着选了哪个文风，`防护开关` 写着 `3/32 · 防429、推剧情`，`破甲` 写着 `Kemini · 21 条`。不用展开就能看全。
- 展开状态会持久化（关掉面板再打开还是原样）；底部有「全部折起 / 全部展开」。
- 面板整体可滚动；拖标题栏移动，拖右下角斜纹缩放，位置和尺寸会记住。
- 标题栏右侧：🌙 切配色、— 收起、✕ 关闭。
- 底部：**小方案**（把当前开关组合存下来，一键切回；右键小圆片删除）、**刷新**（在酒馆里改过预设、这边没跟上时点）、**本组全关**。
- 每次操作**只写回预设一次**，不刷写。

模块分四层渲染：
- **破甲** → 展开后是「骨架下拉框 + 该骨架的档位」
- **单选子集** → 展开后是下拉框（选一个自动关掉同组其他）
- **多选子集** → 展开后是开关排
- **自定义内容** → 展开后是一排输入框

## 自定义内容（自己填）

有些条目不是开关，是**要你敲内容**的。面板给它们真正的输入框，共 6 条：

| 条目 | 行为 |
|---|---|
| `🔴指南（可改）` | 固定开启，只能改内容（作者原话：想要什么效果直接塞这里就能做到） |
| `☀️自定义缝合处` | 固定开启，只能改内容 |
| `🧐用户画像（点进去看）` | 可开关 + 输入框 |
| `自定义禁词` | 可开关 + 输入框（也挂在 DS/GLM 的「模型禁词」档位里） |
| `🤖自定义（字数）` | 在「字数」模块里**选中它**，输入框就地出现 |
| `思维链-自定义` | 在「思维链」模块里**选中它**，输入框就地出现 |

规则：
- 输入框里的内容**改完点「保存」才写回预设**（一次写回）；「撤销改动」只把框恢复成预设里的当前值，不写回。
- 单选模块里选中可编辑项 → 输入框直接摊在下面。
- 开关排 / 档位里的可编辑项 → 旁边挂一个「✎ 填内容」，点开才渲染输入框（否则一排大文本框会把面板撑爆）。
- `custom` 模块是"视图"：其中三条已被各自的模块当选项拿走，所以在两个地方改的是同一个条目，不会不一致。
- 可编辑清单的唯一真相是 `spec/groups.json` 里 `custom` 模块的 `editable` 字段（构建脚本里写作 `EDITABLE_INFO`），每条都带 `hint` 说明什么时候生效、该填什么；构建时会检查缺文案的项。

## 技术口径（重要）

- 读写预设只用酒馆助手 API：`getPreset('in_use')` 读，`updatePresetWith('in_use', updater, { render: 'immediate' })` 写，`replacePreset` 兜底。
- **`prompt_order` 不碰**。酒馆助手的 Preset API 不暴露它（它是酒馆原始存储细节），开关状态直接落在 `prompts[i].enabled`。
- 脚本跑在 iframe 里，所以窗口挂到 **`window.parent.document`**（拿不到父页面时退回本地文档）。这一条不做的话面板会渲染在不可见的 iframe 里。
- 不依赖任何 CDN，纯手写 DOM。
- 条目按**名字**定位。名字对不上的条目会被标成「缺失」并在切换时自动跳过，不会静默改错东西。

## v0.1.0 已实现 / 未实现

**已实现**：悬浮窗（拖动/缩放/记忆/收起/关闭）、白天夜间两套芳乃配色、21 个子集的三种渲染、破甲三组互斥、单选互斥、多选叠加、小方案存取、一次写回、缺失标记、离线预览、24 项逻辑断言。

**未实现**（SPEC 里列了、这一版故意没做）：advice 开关与插入、会话快照、大方案管理、导入导出、存储占用管理、正则门控、芳乃身份层文本、预设本身的组装（目前它作用在**当前载入的任何预设**上，芳乃预设还没生成）。

## 构建与测试

```bash
node tools/build-groups.mjs     # spec/groups.json（子集定义）+ 覆盖率报告
node tools/build-panel.mjs      # 注入 groups → fano-panel.js + preview-host.js
node tools/test-panel.mjs       # 41 项逻辑断言（假 DOM：手风琴/互斥/写回次数）
node tools/check-browser.mjs    # 16 项布局断言（真 Chrome：几何/遮挡/可点击）
```

两层测试分工不同，都要跑：

- `test-panel.mjs` 用极简 DOM 壳跑逻辑——验"点了之后数据对不对"。**它量不出 CSS 布局问题。**
- `check-browser.mjs` 用 headless Chrome 真加载、真点击、量 `getBoundingClientRect` 和 `elementFromPoint`——验"能不能点得到"。

`check-browser.mjs` 需要 Chrome/Edge 派生进程与 IPC，在受限沙箱下会被拒（`OpenProcess: 拒绝访问`），要以更宽权限运行。

## 踩过的坑（改面板时留意）

1. **`.fp-body` 的子项必须 `flex: 0 0 auto`。** body 是固定高度的纵向 flex 容器，内容超出时默认的 `flex-shrink:1` 会把每个 `.fp-mod` 压成 2px（只剩边框）——标题行直接点不到，点哪里都落在后面的分区标签上。表现就是"点名字展不开"，但滚动正常。
2. **`.fp-win` 必须定位。** 它原来是 `position: static`，写在它上面的 `right: 16px` / 拖动时的 `left/top` 全部无效，窗口卡在左上角还拖不动。
3. **窗口要挂到 `window.parent.document`。** 酒馆助手脚本跑在 iframe 里，挂本地 document 会渲染在不可见的 iframe 中。
4. **指针监听只挂一次。** 原来每次 `render()` 都往 window 上再加两个 `pointermove`/`pointerup`，拖一会儿就堆上百个监听器。
